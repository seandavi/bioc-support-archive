# Code of Conduct

This project is part of the Bioconductor community and follows the
[Bioconductor Code of Conduct](https://bioconductor.github.io/bioc_coc_multilingual/), which
is maintained by the Bioconductor Code of Conduct Committee and available in several languages.
It applies to issues, pull requests, reviews and any other discussion about this repository.

## Reporting

If you experience or witness behavior that violates the Code of Conduct, you can report it to the
Bioconductor Code of Conduct Committee:

- through the [reporting form](https://forms.gle/gEWHBWnXvZbEdFsq5), or
- by email to [code-of-conduct@bioconductor.org](mailto:code-of-conduct@bioconductor.org).

If you are uncomfortable reporting to the committee as a group, you can contact any individual
committee member by email or by direct message on the Bioconductor Zulip. Include screenshots or
links where you can. Reports are handled by the committee, not by this repository's maintainers.
